An original ember duel of cards, built for the [make.fun best card game bounty](https://make.fun/bounty/best-card-game-20261122-1826). You and Ashwick, the Cinder Warden, start at 20 life. Each turn you gain an ember crystal and draw a card; creatures take the table and strike at the end of your turn, spells hit at once. Reduce the Warden to 0 life before your own embers gutter out.

Play it: serve `game/` with any static server (`node serve.ts`, then http://localhost:8080) and open `game/index.html` in a desktop browser. Mouse or keys 1–7 pick a card, Enter ends the turn. No network requests, no libraries — plain canvas, ES modules and a WebAudio synth.
